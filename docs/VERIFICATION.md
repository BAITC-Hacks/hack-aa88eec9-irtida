# Проверка основы

Проверено 23 сентября 2026, локально на Windows, Python 3.12 / Node.js 24.

## Успешно

- `python -m pytest -q`: **26 passed**.
- `python -m pip check`: несовместимых зависимостей не найдено.
- `npm run build`: TypeScript и production-сборка Vite проходят.
- `run.ps1`: собирает frontend и запускает FastAPI; страница доступна на 127.0.0.1:8000.
- Через браузер: вход сотрудника, получение рекомендаций по правилам, выполнение практикума, System Design 2 → 3, покрытие 55% → 64%, сохранение после перезагрузки.
- Через браузер: выход, вход HR, отображение дефицитов, отсутствия шага и обновлённой статистики участия.
- Через pytest: права доступа, Origin/заголовок, отключение демо-входа, транзакции и конкурентное выполнение, импорт/повторы/ошибки, отсутствие правил грейда, неизвестные навыки, кэш, лимиты AI, ошибочные ответы и контракты обоих провайдеров с имитированным API.

## Ещё не проверено

- Реальные вызовы OpenAI/NVIDIA: ключей нет, credits не использовались.
- Качество и задержка AI на оригинальном наборе и проверочных профилях жюри.
- Совместимость с оригинальными JSON/CSV: стартовый кит не получен.
- Docker build / Compose: Docker отсутствует в текущем окружении.
- Чистый запуск на другом компьютере и выполнение GitHub Actions.
- Полноценная авторизация для публичного доступа: в основе только локальный демо-вход.

Остаётся одно предупреждение зависимости: Starlette рекомендует будущий переход TestClient с httpx на httpx2. Текущие 26 тестов проходят; предупреждение не скрыто.

В тестовой локальной БД уже есть завершённый практикум после браузерной проверки. В архив БД не входит; при первом запуске из исходников создаются чистые демонстрационные данные.
