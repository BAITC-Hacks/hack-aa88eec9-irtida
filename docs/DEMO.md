# Демонстрация Career Quest

## До защиты

Запустить `start.bat`. Дождаться адреса и открытия браузера. Если 8000 занят, launcher выберет свободный порт. Kit из локального каталога загружается автоматически; ожидаются 200 сотрудников, 40 событий, 60 навыков и 2 743 участия.

На новой базе открыть отдельную ссылку первичной настройки HR, создать первый HR-аккаунт, выдать приглашение одному сотруднику с доступными активностями, зарегистрировать его со своим паролем. В форме входа и регистрации роль выбирается из списка; по умолчанию выбран сотрудник. Не используйте реальные персональные данные. Сохраните рабочую БД; для репетиции можно явно задать отдельный DATABASE_URL.

По умолчанию подбор мероприятий работает в режиме `rules`; это показывает основной сценарий без расходов на API. Для репетиции персональной практики задайте в `.env` `AI_PROVIDER=rules`, `NVIDIA_AI_MOCK=true`, перезапустите `start.bat` и нажмите кнопку практики в профиле сотрудника: ответ обозначен `mock`, ключ и сеть не нужны. Для живой демонстрации задайте `AI_PROVIDER=nvidia`, `NVIDIA_AI_MOCK=false`, серверный `NVIDIA_API_KEY`, `NVIDIA_MODEL=nvidia/nemotron-3-super-120b-a12b` и `AI_DATA_POLICY_APPROVED=true` после разрешения на облачную обработку. После перезапуска проверьте один ответ с режимом `nvidia` и моделью. `server.app.ai.smoke` проверяет прежний OpenAI-адаптер и не подтверждает работу нового NVIDIA-модуля. Режим `fallback` у основного подбора означает подбор по правилам после ошибки или запрета отправки данных.

## Пять минут основного сценария

1. **Проблема.** Разрозненные активности превращаются в понятный следующий шаг. Нет рейтингов результативности или давления на обязательные процессы.
2. **Профиль.** Войти сотрудником. Показать текущую роль/грейд, цель, critical-навыки, историю и доступные квесты. Профили есть также для продаж, HR и поддержки.
3. **Рекомендация.** Запросить 1–3 шага и раскрыть объяснение: грейд, конкретный разрыв, требования следующего уровня, история формата. Блок следующего шага показывает пользу и ожидаемый прирост; участие добровольное. Сравнить это с ошибочным правилом «самый низкий навык».
   Если настроен NVIDIA Career AI, открыть персональные практические задания и показать ссылку на исходное мероприятие. Задание советует, как подготовиться; его отметка сама по себе не меняет уровень навыка.
4. **Результат.** Проверить прогноз прироста, выполнить один квест. Уровень ограничивается gain/max_level из Kit; траектория меняется, после обновления страницы результат остаётся. Автоматического повышения грейда нет.
5. **HR.** Войти HR, показать дефициты, отсутствие следующего шага с причинами, участие, полный каталог и навыки. Открыть сотрудника через команду. HR не может завершить квест за него.
6. **Проверка жюри.** Импорт данных → дополнительные employees.json/activity_history.csv → проверка → подтверждение. Формат оригинальный, без ручного преобразования.
7. **Языки и навигация.** Переключить RU/EN/ҚАЗ. Открыть аккаунт верхней кнопкой. Перейти по breadcrumb, обновить страницу и вернуться кнопкой браузера: раздел сохраняется.
8. **Роли и доступ.** Показать раскрывающийся список из шести ролей. Внутренние права подтверждаются приглашением. Руководитель/супервизор видит свою траекторию и непосредственных подчинённых по manager_id, но не завершает квесты за них. Клиент контакт-центра регистрируется без приглашения и получает отдельный кабинет без внутренних данных; голосовой бот не реализован в рамках этой доработки.

## Если что-то пошло не так

- Занятый порт: открыть адрес, который вывел launcher, либо указать `start.bat 8017`.
- Нет Kit: HR загружает четыре оригинальных файла. Не подменяйте счётчики интерфейса заглушками.
- Нет кандидатов: посмотреть причины — Lead, выполненные требования, prerequisites, ограничения формата/роли/даты. Это допустимое состояние.
- AI недоступен: интерфейс показывает fallback и причину. Зафиксировать ограничение, продолжить сценарий с rules.
- Сетевой сбой после выполнения/импорта: сначала обновить данные, затем решать, нужна ли повторная отправка.
